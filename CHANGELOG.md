# Changelog

## 0.1.0 - 2026-10-21

Initial release.

- Method-first skill for containerized JVM services: protocol, report template, command-safety
  tiers and a symptom-first triage table.
- References for container memory, GC, startup and warm-up, leaks and heap dumps, virtual threads,
  hot paths, dependency tuning, flag verdicts, formulas, A/B testing and rollout.
- Optional add-ons for Spring Boot, Kotlin coroutines and Datadog.
- Claim checking against primary sources (`claims.json`), evals and CI.
