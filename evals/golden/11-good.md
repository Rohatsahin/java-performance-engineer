Concurrency is no longer capped by threads, so the Hikari pool of 10 and the 50-call downstream become the limits. Use one limiter per resource: a semaphore sized to the pool, 10, for the database work and 50 for the downstream calls, each from Little's Law. On JDK 21 synchronized pins the carrier, fixed from JDK 24 (JEP 491); carriers default to the CPU count. Watch jdk.VirtualThreadPinned, set per-call timeouts, and A/B.
